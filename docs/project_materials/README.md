# Project Materials

This folder keeps original project materials and reference files that are useful but should not be mixed with active stage code.

## Folders

- `prompts/`: original task and environment prompts.
- `reference_notebooks/`: reference notebooks found during development.
- `original_starter/`: teacher starter files kept unchanged for reference.

## Active Runtime Resources

The active project code uses files under:

```text
resources/
```

The former `original_resources/` backup was removed during the directory cleanup
because every file was byte-for-byte identical to its canonical copy under
`resources/`.
